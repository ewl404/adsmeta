# **App Name**: Scratch2Cash

## Core Features:

- Scratch Card Simulator: Interactive scratch card simulation at the top of the page to immediately engage visitors. Scratching the card does not win any prize but helps attract interest.
- Value Proposition Messaging: Headline and subheadline to clearly communicate the value proposition.
- WhatsApp CTA Button: Prominent, vibrant CTA button that redirects users to a WhatsApp link for direct communication.
- Personalized Messaging: AI tool to personalize headline and subheadline text based on the inferred profile of the visitor. A/B testing can evaluate different options.

## Style Guidelines:

- Primary color: Black (#0a0a0a) for the background.
- Secondary color: Vibrant yellow (inspired by the logo) for titles and highlights.
- Accent color: Strong green (based on the logo's clover) for elements, icons, and buttons.
- Font: Bold, legible, and modern typography.
- Use WhatsApp icon next to the CTA text.
- Minimalist but striking layout with high contrast, optimized for mobile.
- Gentle animation on the scratch card reveal for added engagement.
